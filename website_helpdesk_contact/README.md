# Website Helpdesk Contact

Create helpdesk tickets directly from the public **Contact Us** form.

## Features
- Replaces the contact form target with `helpdesk.ticket`
- Whitelists ticket fields for website form submissions
- Keeps visitor name/email/subject/question mapped to ticket fields

## Usage
1. Install the module.
2. Open the website Contact Us page and submit the form.
3. A new helpdesk ticket is created with the provided details.
