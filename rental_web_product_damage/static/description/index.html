Rental Product Damage Tracker

Odoo 18 Module for Managing and Displaying Rental Product Damages

Overview

The Rental Product Damage Tracker module provides an efficient way to record, monitor, and display damages associated with rental products. It integrates seamlessly with your existing Odoo Rental or Sales workflow.

Key Features

  • Track damages at check-in, check-out, or ad-hoc times.
  • Attach images to each damage report or damage line.
  • Define severity levels (Minor, Moderate, Major).
  • Manage states: Draft, Confirmed, Closed.
  • Smart button on product form to open public damage page.
  • Public page via token (e.g. /rental/damage/<token>) to share with customers.
  • Auto-refresh token after rental completion for security.
  • Public page displays only open damages, with clean responsive layout and photos.
