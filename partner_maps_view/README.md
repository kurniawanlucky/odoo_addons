# Partner Maps View

Shows partner geolocation on an OpenStreetMap widget inside the partner form.

## Features
- Adds a map under the Geolocation section of partner form
- Uses the `maps` widget (Leaflet + OpenStreetMap)
- Works with `partner_latitude` and `partner_longitude`

## Usage
Install the module and open a partner form. The map appears after the Geolocation group.

## Dependencies
- `base_geolocalize`
- `web_maps`
