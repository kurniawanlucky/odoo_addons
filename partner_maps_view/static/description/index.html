Partner Maps View

Partners Geolocation OpenStreetMap

Adds a map widget inside the partner form to display the partner location based on partner_latitude and partner_longitude.

Key Features

  • Map appears after the Geolocation group.
  • Uses Leaflet with OpenStreetMap tiles.
  • Read-only display or editable marker placement (via widget options).

Dependencies

Requires base_geolocalize and web_maps.
