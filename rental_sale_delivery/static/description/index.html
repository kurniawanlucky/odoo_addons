Rental Sale Delivery

Integrate Rental Orders with Delivery Carriers

The Rental Sale Delivery module adds delivery carrier options such as Uber, Gojek, and Grab for rental-based sales orders.
It extends functionality from:

  • rental_product_base – provides product rental core (durations, pricing, availability)
  • rental_sale_product – enables rentals to be sold via Sales Orders

This module ensures rental items can include a chosen delivery service during checkout or sales processing.

Installation Order

  1. Install rental_product_base
  2. Install rental_sale_product
  3. Then install rental_sale_delivery

Features

  • Add predefined delivery carriers: Uber, Gojek, and Grab.
  • Each delivery option is automatically linked to its own product.product.
  • Supports fixed delivery pricing or integration with future rate logic.
  • Can be used in combination with rental products in sales orders.
  • Compatible with standard Odoo delivery carriers and sales workflow.

Notes

This module is especially useful when rental items require on-demand transport or third-party logistics support. For instance, if a rented bike or camera must be delivered via Gojek or Uber.

Future enhancements can include:

  • Automatic distance-based pricing
  • Integration with real delivery APIs
  • Tracking number and estimated time updates
