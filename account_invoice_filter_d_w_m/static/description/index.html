Smart Invoice Filtering

This module enhances the Invoices page by adding quick filters so you can easily view and analyze invoices by date ranges:

  • Today — View invoices created today.
  • This Week — Monitor all invoices issued this week.
  • This Month — Quickly check monthly billing performance.
  • This Year — Get a yearly overview of all invoices.

Simple to use — just install and start filtering your invoices immediately. No configuration required.
