Rental for Sales & Website (Odoo 18)

Pick rental dates first, see only available products, correct pricing across website & backend, and prevent double booking.

Odoo 18 Website + Sales No double booking

Features

  • Date-first flow on sale.order.line form — pick Rental Start and End before product.
  • Availability filter: product dropdown shows only items free in the chosen window (no overlap with confirmed/done orders).
  • Accurate pricing with weeks/days/hours + minimums + rounding, mirrored on Website & Sales.
  • Website integration: Product page date inputs, live price preview, cart shows dates & breakdown, add-to-cart enforces availability.
  • Checkout-safe: Re-applies rental price after address submit/pricelist changes so it never reverts to catalog price.

How it works

  1. User selects start/end → system computes hours and builds a weeks/days/hours breakdown.
  2. Minimums & rounding are applied, price computed from rental_price_per_week/day/hour.
  3. Availability excludes items with overlapping rentals in sale/done states.
  4. Website/cart lines store the dates; pricing is re-enforced at checkout steps.

Installation

  1. Copy the module into your addons path.
  2. Update apps list and install.
  3. Ensure your products to rent have type = rental and rental price fields set.

Configuration

  • On Product Template: set rental_price_per_hour/day/week and minimums.
  • On Sales Order Line: date fields are first; the product domain auto-filters by availability.
  • Website PDP shows date inputs; enabling live price preview requires the provided JS asset.

Usage (Website)

  1. Open a rental product page → choose Rental Start/End.
  2. Check live price preview → add to cart.
  3. Cart line displays dates and the duration breakdown.
  4. Proceed to checkout — pricing remains the rental price.

Usage (Sales)

  • Click Add Rental Line wizard on an order (or add inline).
  • Pick dates → select from available products → price is computed automatically.

Security

  • Wizard is TransientModel (no extra rules needed).
  • Website writes are done with proper sudo on the line after cart update.

Technical notes

  • Overlap rule: (start <= existing_end) AND (end >= existing_start), states in ['sale','done'].
  • Pricing is enforced on:
    • Website add-to-cart
    • /shop/address/submit post (override)
    • Partner / Pricelist onchanges (server-side safeguard)
  • Optional: prevent cart line merge using a “Rental Period” no-variant attribute.
