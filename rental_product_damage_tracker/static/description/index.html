Rental Damage Management

This module adds a comprehensive damage tracking system for rental products, such as vehicles or equipment. It helps rental companies record and monitor damages before and after each rental period.

Key Features

  • Record and manage damages per product or vehicle.
  • Separate header (rental.damage) and line (rental.damage.line) structure.
  • Fix damages one by one at the line level.
  • Automatic header state updates when all findings are fixed.
  • Support for damage severity, area, photos, and descriptions.
  • Smart button on product template to show open damages.
  • Integrated with Rental and Product modules.

Rental Damage Form with line details and photos

Usage

  1. Create a new Damage Report for a rental product.
  2. Add findings (damage lines) with area, severity, and photos.
  3. Confirm the report to start the repair tracking.
  4. Mark each line as fixed when repaired.
  5. Once all are fixed, the report auto-closes.
